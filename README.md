# Iron-Tigers-Team-4041-Website

This repository serves as the GitHub repository for the website of the FRC team Iron Tigers (Team 4041).

## Next.js setup

The site is now scaffolded as a Next.js app using TypeScript and the App Router. The current static HTML files remain in place while the app is migrated incrementally.

### Scripts

- `npm run dev` - start the local development server.
- `npm run build` - create a production build.
- `npm run start` - serve the production build.
- `npm run lint` - run ESLint.
